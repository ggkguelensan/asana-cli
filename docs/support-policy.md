# Поддерживаемые платформы

Runtime: macOS и Linux, Bun версии из package.json.

- `asana-cli-darwin-arm64`
- `asana-cli-darwin-x64`
- `asana-cli-linux-arm64`
- `asana-cli-linux-x64`
- `asana-cli-linux-arm64-musl`
- `asana-cli-linux-x64-musl`

Авторизация: macOS Keychain, Linux Secret Service или переменные окружения.
Проверки новой версии приложения и самообновления в runtime нет.
Новые сборки устанавливаются явно; установленная версия отображается через `--version`.
