# Тестирование

`bun run check` выполняет проверку типов, платформ, качества кода, release workflow,
сборку, проверку публичного контракта бинарника и тесты.
`bun run test:black-box` собирает CLI и запускает только проверки через исполняемый файл.
Тесты не требуют реального PAT и не выполняют запросы к рабочей Asana.
SDK integration tests используют локальный HTTP-сервер; black-box тесты изолируют HOME/XDG.

Release tooling сохраняет шесть целевых сборок, SPDX SBOM, воспроизводимую сборку,
SHA256SUMS и Sigstore attestations. Проверки установки клиентских интеграций удалены.
`bun run check:release` дополнительно проверяет release-контракт собранного бинарника.
Кроссплатформенные сборки и подписи проверяются release workflow на соответствующих runner.
